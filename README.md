# Concept pages

Unofficial concept works made with AI tools (mostly Claude Code). Not affiliated with any brand.
Prices, shops and shipping terms on the pages are fictional.

- `onitsuka/` an Onitsuka Tiger-style concept store (original shoe design, no brand marks)
- `tanaka65/` a Tanaka 65 concept story page
- `medicube/` scenes for a medicube Booster Pro X2 concept film (Blender, scripted), with the scripts in `medicube/tools/`

If you represent a brand shown here and want a page changed or removed, open an issue in this repository.
